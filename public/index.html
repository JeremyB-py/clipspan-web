Features

Features

ClipSpan keeps clipboard history on your devices and lets you send items between phones and computers when you choose to.

  • History

    On-device clipboard history

    Recent clips stay searchable on the device that captured them. Removed items can be restored from Recently removed.

  • Send

    Send Clip between paired devices

    Choose when an item should move instead of syncing every copy automatically. Share sheet and selected text use the same Send Clip action.

  • Pairing

    Local network pairing

    Pair over your LAN with a QR code, without an account. Local-only mode never contacts ClipSpan servers.

  • Android

    One Android app, including the keyboard

    History, pairing, and ClipSpan Keyboard ship in a single install. Enable the keyboard in Android settings to paste into any app. Sync stays off in password fields.

  • Media

    Images and other multimedia

    History can hold text and images. Files and links are in active testing. Automatic sync still respects your size and sensitive-content settings.

  • Account

    Optional account, backup, and relay

    Sign in to ClipSpan Cloud for encrypted history backup and text relay when you are off the LAN. Same-account devices on the same Wi-Fi can pair without a QR scan. Self-host with a custom Account API URL.

Privacy

How clipboard data is handled

ClipSpan defaults to local use and makes cloud sync optional. See the privacy policy.

  • Yes

    Is clipboard data end-to-end encrypted?

    On the optional account/relay path, payloads and credential vaults are end-to-end encrypted. Servers do not receive clipboard plaintext.

  • Yes

    Can it work without a cloud service?

    Yes. QR pairing on the LAN works with no account. An account uses ClipSpan Cloud. Self-host with a custom Account API URL.

  • Yes

    Is history stored on-device?

    Yes. History lives on your devices. Cloud history backup, when used, is encrypted under keys your clients hold.

Defaults and choices

  • Synchronization is optional. Send Clip moves an item without turning on automatic sync.
  • Password fields on Android keep sync actions disabled.
  • ClipSpan Keyboard can see text in the focused field, like any Android keyboard. Keystrokes stay on the device unless you copy or send a clip.
  • You choose whether to enable account sync at all. Encrypted history backup is optional.
  • Diagnostics and bug reports omit clipboard contents, tokens, and pairing secrets.
  • Creating an account uses ClipSpan Cloud (api.clipspan.com). Relay moves text when you are off the LAN.
  • Self-host with a custom Account API URL.
  • Local QR pairing stays the default if you never sign in.
