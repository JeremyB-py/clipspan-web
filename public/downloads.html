Linux apt

Debian and Ubuntu (amd64). The repo is the same tester password, sent as HTTP Basic (username clipspan): 

curl -fsSL -u "clipspan:YOUR_PASSWORD" https://clipspan.com/apt/install.sh | sudo bash

The script asks for the password again so apt can keep using the repo. Later updates: sudo apt update && sudo apt install clipspan
