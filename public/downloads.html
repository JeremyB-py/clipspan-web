Linux apt

Debian and Ubuntu (amd64). The install script needs your tester code, sent as HTTP Basic (username clipspan). Updates through apt don't. 

curl -fsSL -u "clipspan:YOUR_CODE" https://apt.clipspan.com/install.sh | sudo bash

Use apt.clipspan.com, not a path on clipspan.com. Later updates: sudo apt update && sudo apt install clipspan
