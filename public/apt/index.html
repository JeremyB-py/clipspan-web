ClipSpan

Clipboard history and sync for Android, Linux, and Windows.

Linux (Debian / Ubuntu, amd64)

curl -fsSL https://apt.clipspan.com/install.sh | sudo bash

That adds an APT source and installs clipspan. Later updates: sudo apt update && sudo apt install clipspan.

Uninstall: sudo apt remove clipspan.

Windows, Android, and other Linux downloads

Windows installers and the Linux AppImage are on clipspan.com/downloads. Android installs through Google Play's test: sign up with your phone's Google account.
