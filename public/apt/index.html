ClipSpan

Cross-device clipboard history. Testers: Linux first, then the Android APK from GitHub Releases.

Linux (Debian / Ubuntu, amd64)

curl -fsSL -u "clipspan:YOUR_PASSWORD" https://apt.clipspan.com/install.sh | sudo bash

Replace YOUR_PASSWORD with the tester password. That adds an APT source and installs clipspan. Later updates: sudo apt update && sudo apt install clipspan.

Uninstall: sudo apt remove clipspan.

Android and Windows

GitHub Releases (APK, AppImage, Windows installers when built).
