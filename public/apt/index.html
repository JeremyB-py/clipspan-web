Linux apt

Debian and Ubuntu (amd64). This repository uses the same tester password as downloads.

Install

Username is clipspan. Replace YOUR_PASSWORD with the tester password: 

curl -fsSL -u "clipspan:YOUR_PASSWORD" https://clipspan.com/apt/install.sh | sudo bash

The script asks for the password again so apt can keep using this repo. Later updates: sudo apt update && sudo apt install clipspan

Uninstall: sudo apt remove clipspan

Android, Windows, and AppImage builds are on tester downloads.
